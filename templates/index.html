快照字段

数字内存字段默认使用 MiB；也支持 512Mi、2Gi 等 Kubernetes 风格字符串。

节点 nodes[]

  • name：节点名称
  • zone：节点可用区
  • allocatableMemoryMiB：可分配内存

Pod pods[]

  • name / node：名称与所在节点
  • app：应用标识，相同 app 视为副本
  • type：online 或 batch
  • memoryRequestMiB：内存请求
  • volumeZone：卷可用区；无卷可留空
  • interruptible：是否可中断
只有 type: "batch" 且 interruptible: true 的 Pod 会被选作停用对象。
